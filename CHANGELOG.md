# Changelog

## 0.1.0 – Unreleased

- `[[wikilinks]]` to journal entries and pages, with `#section` and `|alias` support
- Autocomplete when typing `[[` in the journal editor
- Unresolved links create the missing note when clicked
- Links to actors, with `[[Actor:Name]]` for names shared with a journal entry
- Wikilinks and autocomplete in actor biographies and other rich-text fields, for any game system
- Graph view of journal entries, actors and missing notes, with search, filters, zoom and drag
- `Ctrl+Shift+G` keybinding and Graph buttons in the Journal and Actors sidebars
- English and Brazilian Portuguese translations
